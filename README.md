# Terminal Game Hub

A simple, standalone command-line application that bundles three mini-games behind one menu: Tic Tac Toe, Rock Paper Scissors, and Number Guessing.

## Requirements
- Node.js 14+

## Run it
```bash
node app.js
```
(or `npm start`)

## Games Included
1. **Tic Tac Toe** — Two-player local game on a 3x3 grid.
2. **Rock Paper Scissors** — Play vs. computer with score tracking.
3. **Number Guessing** — Guess a number between 1 and 100 with hints.
4. **Exit**
